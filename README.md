1) SQL.txt содержит скрипт для создания и заполнения трехтабличной базы данных (Пользователи, комментарии, результаты пользователей в Cookie Clicker);  
2) Папка Images хранит фоны разделов сайта;  
3) Папка Dowloads хранит игровые миры, которые доступны для скачки в разделе "Скачать миры";

PHP модули:  
- Авторизация и регистрация пользователей с различными проверками и модальными окнами с выводом ошибок/сообщенией (выбранный логин занят, первый и второй пароли не совпадают, неправильная комбинация логина-пароля, успешная регистрация/авторизация);  
- Создание сессии при авторизации, открытие скрытого раздела "Мини-игра" в хедере и возможности оставлять комментарии
в разделе "Отзывы" (без авторизации доступен только просмотр комментариев других пользователей),
появление в хедере команды "Выйти". При использовании указанной команды она из хедера пропадает и происходит
переход назад на страницу авторизации с появлением модального окна с сообщением о выходе;  
- Личный кабинет с командой "Выйти" и выводом информации о пользователе (все комментарии, рекорд в Cookie Cliker, данные авторизации (скрыты));    
- Раздел отзывов, также присутствуют модальные окна;  
- Мини-игра с возможностью записывать результат и таблицей рекордов с проверкой, побит ли предыдущий рекорд данного пользователя, модальные окна с выводом информации о том, побит рекорд или нет;
